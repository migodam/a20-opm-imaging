# A22 实现说明草稿：接口、物理单位与证据边界

本稿供主线程审查定稿，依据冻结配置、预注册、当前源码及已保存的实现验证摘要。它说明已经写入代码的功能和仍缺失的条件，不汇总恢复实验，不作科学结论。实现沿用声明的 A21 冻结基线 `source_freeze=8aa2d5d…`，没有新增完整性哈希检查。

主接口保持用户接受的命名。下表中的“小模型”指固定电流子空间中的 Galerkin 模型；第五接口的底层 QP 是 `constrained_material_solve`，两者职责不同。

| 接口 | 模块 | 输入与输出职责 |
|---|---|---|
| `build_anchor` | `src/a22/online.py` | 接收已知几何和声明背景，构建并计费完整前向状态，返回 `Anchor`、噪声参考与来源记录。 |
| `build_opm` | `src/a22/online.py` | 从同一背景状态构建固定浅层 O/P/M 模型，返回基底、Schur 反馈、投影及实际秩。 |
| `material_features` | `src/a22/online.py` | 通过材料注入 B、小核求解和接收 S 的已投影像生成 `MW`、`PMW`、`AW`；不请求完整材料 J/H。 |
| `build_split` | `src/a22/core.py` | 在固定 32 维材料坐标内构建互补的 `Vp`、`Vrem` 和读出 D，返回候选分块及其审核量。 |
| `evaluate_recovery` | `src/a22/evaluate.py` | 将观测减去背景预测并白化，调用底层约束 QP，返回一次材料子问题的系数、残差与 KKT 审核。 |

`assets.py` 和 `prepare.py` 提供几何、选定观测成员及在线资产；`features.py` 提供方向描述和误差预算；`offline_assets.py` 与 `evaluate.py` 管理评估标签及恢复；`budget.py`、`validation.py` 分别负责计费边界和实现健康检查。这些支持模块不替代主接口，也不意味着条件性成像与学习阶段已经完成。

材料坐标来自已知网格，不拟合观测或对象真值。空间基 H 包含八个八分区指示列，以及每区一个中心化局部 x 方向细节列，共 16 个实列。取空间材料基 `Qχ=H/√v`，其中 v 为单元体积，因此 `v QχᵀQχ=I`。32 个实系数按“16 个实部、16 个虚部”排列，材料增量为 `Δχ=Qχ θR+i Qχ θI`；在这个固定子空间内，体积加权材料范数就是系数欧氏范数。粗尺度索引为 `[0:8,16:24]`。电流则采用偶极矩除以 `√v` 的单位；材料空间和电流空间的基不能混用。`Vp/Vrem` 仅是固定材料图内的互补坐标，W 外材料另行记录，不能自动称为已证实的全波可恢复与不可恢复空间。

六个照明源以原始方向/极化顺序进入计算。每个源先排列接收通道实部，再排列同一源的虚部，随后按源拼接；64 个接收位置、每处两个复通道对应每源 128 个复通道，因而 `AW` 为 `1536×32` 实矩阵。`MW` 与 `PMW` 保持复数，形状为 `(6,q,32)`，q 是实际电流秩。

噪声采用 proper complex Gaussian 约定：实部、虚部独立，方差各为 `σc²/2`。参考 `σc` 固定为已知非零背景预测数据 RMS 的 0.01 倍，白化乘子为 `√2/σc`；单位噪声水平对应白化后每个实通道方差为 1。参考尺度不取对象真值或实测数据 RMS，也不沿用旧目标函数归一化。QP 内为数值求解而设置的目标函数尺度不改变这一测量噪声定义。

在线电流模型固定为 `U8/O4/P4/M4`、degree 1、电流秩上限 32；线性相关方向可去秩，但不搜索更大秩或阶数。O 的测量探针显式传入固定随机数生成器的探针，绕开默认残差列，因而基底构造不依赖噪声观测。六源注入先完成再压缩。总电流基包含 U，保留直接通路；采用 Galerkin 投影和同一小核 LU 的作用/伴随。无效核直接报错，没有空 U、Petrov、完整求解回退，也没有抖动或伪逆救援。

在线与离线边界落实在数据成员和接口能力上。在线读入仅选 `points/data0/init`，核对背景 `0.1+0.04i` 与原生成来源一致；受限构建视图屏蔽 truth、teacher、完整材料 J/H 和晚期状态 oracle。方向及预测预算先冻结，评估器随后才可通过离线角色打开完整 J 和标签。对象材料仅存于独立的 `data/a22/offline_eval` 命名空间，经独立清单读取，不能作为在线构建输入。行中的 `evidence_scope='deployable'` 描述在线特征的来源边界，不授予部署方法读取评估标签或完整 J 的权限。

有限幅度标签以原实际对象材料为中心，再加入固定材料图中的目标方向和完整互补扰动；在线 anchor 始终是已知均匀背景。两者不能混为“均匀背景上的四个几何测试”。评估器可计算对象材料的固定图投影及 W 外残差，在线预算只使用声明的先验幅度，不以实现后的真值范数替代。标签前向直接调用模型状态构造并计费，避免激活另一 Adapter 算子而破坏背景投影缓存。原观测生成网格声明为 n14，保存的对象材料及新有限标签使用 n12 求解网格；二者保持区别，旧观测不充当同网格精确标签。

与 T10 有关的有限幅度预算已纳入实际 Clausius–Mossotti/辐射反作用极化率的二阶项：实现使用 `a''=-18 v c/(3+cχ)³`，其中 `c=1-i·3k³v/(6π)`，并显式检查区域分母下界。多重散射的反馈余项还需要整个声明扰动区域上的 resolvent 稳定裕度。代码仅给出充分的 Neumann 型背景检验；裕度缺失时保留明确的经验余项标记，不借完整逆或真实标签制造证书。即使局部模型分量具备界，实际对象仍可能超出声明的 0.25 逐单元先验，且可能具有 W 外成分。因此项目预测继续标为 `empirical_indicator`，`full_model_uniform_certificate=False`，不能称为严格 T10 全域证书。这个范围来自实现与预注册，尚不是实验支持的科学判断。

底层材料 QP 保持实部下界 −0.5、虚部下界 0 以及原二次目标。固定 n12 图有 `2×1728=3456` 个逐单元不等式；已实施的优化只按完整 `(系数行,下界)` 精确相等去重，在该固定图和均匀背景下保留 32 个不同半空间供 SLSQP 使用。它没有合并近似相等约束，也不改变可行域。求解后的可行性、互补性、法向与 KKT 仍用完整原 C/lower 审核，终点不靠优化器成功标志或后裁剪认定有效；不合格结果保留为 `INVALID_QP`。

部分恢复读取全部既有行，保留无效 QP 和失败记录。案例键包含场景、方向、幅度级、噪声水平、抽样及干预；既有合格 OK 和终止性 `INVALID_QP` 均不重跑，后者保持失败及统计不合格状态。未完成场景重新构建并支付在线 anchor/Q，离线读取前检查新旧 AW 的相对差异不超过 `1e-9`，并比较科学来源、方向和冻结预算。原文件不被覆盖，重新生成的比较另存 resume audit。仅分块正交性与 nuisance leakage 两个无量纲恒等式残差按既有 `1e-9` 容差分别检查并记录差异；其他比较维持严格规则。

完整 J 和有限标签仅在在线预测冻结后重放缓存。新缓存验证材料中心、网格、图、采集布局、白化、配置及系数/方向/幅度/六源顺序；旧 JF-only 缓存依赖兼容的成套在线冻结记录，旧有限标签缺失数值 backward-residual 收据的事实另行标记。成功验证的重放支付读取/CPU 成本并记录 `offline_cache_hits`，不新增 F 或完整 J 构建次数；缺失缓存走正常付费路径，不兼容缓存拒绝。动作、失败、中断和重建均进入原账单，CPU 与 GPU 占用分别记账，嵌套 span 不与整个 job 收据重复累加。

已有实现验证记录覆盖打包/源置换、真正 Gaussian 白化、材料度量、有限差分、JVP/VJP 与 B/S/L 伴随、Schur/完整 Galerkin 及直接通路、两侧缺陷恒等式、缓存失效、无回退和约束 KKT。CUDA 小网格健康记录使用真实 DenseDDA、4³ 单元、同一六源 128 通道及完整 32 实材料图；理论脚本保留原协议输出。它们只检查实现一致性，不承担恢复实验或科学门槛判定。旧通用 CUDA HEALTH 仍保留 Windows 记账写入失败，后续按作业目录保存记录，不能抹去前者。
